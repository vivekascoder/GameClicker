GameClicker

Bind keyboard keys to macOS mouse clicks at fixed screen coordinates, with optional app and window filters.

View on GitHub Run locally

Run Locally

git clone https://github.com/vivekascoder/GameClicker.git
cd GameClicker
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp config.example.json config.json
python game_clicker.py

Grant your terminal app Accessibility and Input Monitoring permissions in macOS before running the listener.

Configure Coordinates

Print the current pointer position, then copy the values into config.json.

python game_clicker.py --show-position

Or save the current pointer position to a key binding after a delay.

python game_clicker.py --calibrate w --delay 3

Limit to a Window

Inspect the focused app and window title.

python game_clicker.py --print-window

Then edit config.json.

{
  "only_when": {
    "frontmost_app_contains": "Your Game App",
    "window_title_contains": "Your Window Title"
  }
}

Hill Climb Racing

The included example maps D and A to hold-style clicks at relative screen positions.

python game_clicker.py hillclimbracing.json

The included hillclimbracing.json file uses this configuration.

{
  "only_when": {
    "frontmost_app_contains": "Hill Climb",
    "window_title_contains": ""
  },
  "bindings": {
    "key1": {
      "key": "d",
      "coord": {
        "x": 0.9,
        "y": 0.9,
        "relative": true
      },
      "button": "left",
      "mode": "hold"
    },
    "key2": {
      "key": "a",
      "coord": {
        "x": 0.1,
        "y": 0.9,
        "relative": true
      },
      "button": "left",
      "mode": "hold"
    }
  }
}

Binding Modes

  • tap: click once per key press
  • hold: mouse down on key press, mouse up on key release
  • repeat: keep tapping while the key is held
